# PinTop 0.1.4 按钮对齐与本机复测

环境：Apple Silicon、macOS 27.0.1、Xcode 27.0、SIP 开启。图形操作在当前源码的 Debug 构建上完成。

| 项目 | 本机观察 |
| --- | --- |
| 按钮布局 | AppKit `imageHugsTitle` 让“选择窗口”的图钉和文字作为整体居中；控制窗口截图已目视检查。 |
| 构建与签名 | Xcode Debug 构建及 `codesign --verify --deep --strict` 通过。 |
| 多窗口 | 两个独立临时 AppKit 窗口依次置顶；取消第一个后第二个保持置顶，结束时恢复进程退出。 |
| 图形界面 | 在窗口列表置顶测试窗口，角标出现在目标右上角。通过角标直接取消后，控制窗口显示 `0 个已置顶`，目标行恢复“置顶”。 |
| 移动、缩放和输入 | 置顶后通过测试窗口自身按钮移动和放大，角标位置读回为目标右边缘向左 140 点、顶部向下 4 点，且位于目标上方；测试窗口文本框可写入文字。 |
| 取消与清理 | 从移动缩放测试窗口的角标直接取消后，角标窗口消失，恢复记录标记 `disarmed`，没有存活的恢复进程。测试夹具已退出。 |

标题栏自动拖拽未得到可靠结果，移动验证使用测试窗口自身按钮。菜单、输入法候选窗、多桌面、多显示器和 macOS 14–26 未在此次复测中覆盖。Release 下载包的图形交互没有单独重复授权测试；与已验收的 Debug 构建同源。
