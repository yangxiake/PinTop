# PinTop 0.1.3 界面与角标跟随验收

环境：Apple Silicon、macOS 27.0、Xcode 27.0、SIP 开启。目标是 `PinTop.xcodeproj` 构建的当前 `build/PinTop.app`；测试窗口是本地独立 AppKit 夹具，测试结束后已关闭。

| 项目 | 观察结果 |
| --- | --- |
| Xcode 工程 | Debug 构建成功，`codesign --verify --deep --strict` 通过；应用包内含 `PinTop.icns`。 |
| 控制窗口 | SF Symbols 图钉、设置和动作图标可见；窗口列表显示目标应用的原生图标、名称和辅助功能读取的窗口标题；未授权时给出明确提示。 |
| 几何跟随 | 角标以 60 Hz 检查屏幕窗口位置，只在目标坐标变化时调整。独立测试进程通过辅助功能移动 440×292 点的夹具窗口 120×85 点，角标最终同向移动 120×85 点；恢复原位后角标也恢复。窗口移动动画中曾在 50 ms 采样点观察到一帧左右的短暂偏移，不能据此声称像素级零延迟。 |
| 当前应用实际操作 | 在 PinTop 窗口列表中置顶临时窗口 A，角标的图钉与“已置顶 · 取消”可由图形辅助功能读取。拖动 A 后，CG 窗口坐标为 `(173,177,440,292)`，角标为 `(473,181,132,30)`，即保持在目标右上角。直接点击角标后列表恢复“置顶”，无恢复 helper 或 journal 残留。 |
| 清理 | 测试夹具 A/B 已结束；临时预览 app 已从 LaunchServices 注销并移到废纸篓。当前工作区只有一份可运行 `build/PinTop.app`。 |

菜单和输入法候选窗遮挡仍是已知限制；多显示器、跨屏和 macOS 14–26 的完整功能没有在这次验收中覆盖。
