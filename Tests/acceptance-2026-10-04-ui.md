# PinTop 0.1.5 界面一致性复测

环境：Apple Silicon、macOS 27.0.1、Xcode 27.0、SIP 开启。图形操作在同源 Debug 构建上完成；下载包为 Release 构建。

| 项目 | 本机结果 |
| --- | --- |
| 按钮比例 | 授权、选择、刷新、全部取消、列表置顶和窗口取消按钮统一为 96×28 点；按钮文字与 SF Symbols 图标均为 12 点。截图中图标和文字居中，按钮等高等宽，四字文案完整显示。列表按钮的右边缘与授权、全部取消按钮以及设置开关的右边缘对齐。 |
| 反馈 | 各按钮使用同一个 0.14 秒悬停和按下反馈实现；系统开启“减少动态效果”时停用动画。刷新按钮的悬停状态已目视检查。 |
| 布局 | 列表在 3 个可选窗口时缩短高度，偏好设置紧接列表；窗口较多时保持滚动列表。 |
| 授权 | 列表右对齐修正后再次构建，更新本机对当前 PinTop.app 的辅助功能授权；控制窗口读回“已授权”。 |
| 操作 | 点击“选择窗口”进入选择状态，点“取消选择”返回；右对齐修正后，在列表置顶临时 AppKit 窗口，窗口右上角显示“取消置顶”按钮；点击后控制窗口读回 `0 个已置顶`，目标恢复“置顶”。测试夹具已退出。 |
| 构建 | Debug 构建和 `codesign --verify --deep --strict` 通过；Release ZIP 另行验证签名、arm64 架构、SHA-256 和归档完整性。 |

没有量化动画帧率或视觉延迟。菜单/输入法候选窗、多桌面、多显示器以及 macOS 14–26 的完整功能仍未在本次复测中覆盖；Release 包没有单独重复图形授权测试。
